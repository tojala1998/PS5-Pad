PS5 Pad 0.4.14 (build 20)

- Includes PS5 helper 2.8, updated to request full shutdown through
  sceSystemStateMgrTurnOff instead of the ShellCore shutdown call that entered
  Rest Mode on the tested PS5. Physical full-shutdown behavior is not yet
  confirmed on the console; a successful API response alone is not proof.
- Disables Power Off when connected to helper 2.7 or older, even if that helper
  advertises the Power Off capability. All other controller features remain
  available when using a compatible older helper.
- Reuses an already-running helper without stopping or replacing it silently.
  To use the updated Power Off command, replace the running older helper 2.7
  with the new helper 2.8 when convenient.
- Preserves console discovery, controller operation, Kodi controls, and SideStore
  signing/install behavior. No settings are preseeded or migrated.

A genuine full shutdown ends the PS5 jailbreak. You must turn on the console
and run the jailbreak again before using PS5 Pad.
