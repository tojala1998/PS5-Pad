Automatically checks the running PS5 helper before enabling controls on every connection. If it is older than the bundled helper, PS5 Pad confirms release of its own virtual controller, requests a clean helper stop, waits for acknowledged shutdown, connection closure and a refused service connection, then loads and verifies the replacement. Current and newer helpers are reused without restarting their controller session.

Failed removal, ambiguous shutdown, blocked network access, an invalid greeting or a stale replacement stops the update instead of sending another helper. Very old helpers without acknowledged controller removal require a manual restart. An ELF loader or Payload Manager must be available to start the replacement. Updating an older helper ends its virtual-controller session; normal initialization/profile selection may follow.

This release still bundles the unchanged controller helper 2.7. A running 2.7 or newer helper is deliberately not restarted. Full Power Off remains separate and was user-confirmed in 0.4.16. Built with the original LLVM 18 / iPhoneOS 16.5 SDK toolchain. Local policy, host-daemon socket and archive checks passed; the automatic replacement flow still needs verification from the iPhone.
